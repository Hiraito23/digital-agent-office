# Playbook Penjualan Digital

## When to Use

- Menyusun strategi dan materi penjualan online: profil pelanggan, penawaran, skrip chat, email, follow-up, penanganan keberatan, atau pipeline prospek.
- Menghitung target penjualan dan apa yang dibutuhkan untuk mencapainya.

## Procedure

**1. Mulai dari angka (kalkulator target)**

```
Target omzet / bulan                      = T
Harga rata-rata per transaksi             = H
Transaksi yang dibutuhkan                 = T / H
Konversi prospek -> pembeli (asumsi)      = k   (mulai 5-10% untuk chat hangat, 1-3% untuk dingin)
Prospek yang dibutuhkan                   = (T / H) / k
Prospek per hari kerja                    = prospek / 22
Margin kotor per transaksi                = harga - HPP - biaya kanal
```

Tulis semua asumsi sebagai asumsi. Bila margin per transaksi lebih kecil dari biaya mendapatkan pelanggan, katakan itu sejak awal.

**2. Profil pelanggan ideal (ICP) dan pekerjaan yang ingin diselesaikan**

| Pertanyaan | Isi |
| --- | --- |
| Siapa (usia, peran, kota, penghasilan) | |
| Situasi pemicu: kapan mereka mulai mencari | |
| Masalah utama dan dampaknya (waktu, uang, malu) | |
| Cara mereka menyelesaikannya sekarang | |
| Alasan membeli | |
| Alasan menolak (harga, tidak percaya, tidak mendesak) | |
| Tempat mereka berada (kanal) dan jam aktif | |

**3. Penawaran yang sulit ditolak** (urutan): hasil yang dijanjikan -> bukti (testimoni asli, angka, demo) -> isi paket -> harga dan perbandingan nilai -> pengurang risiko (garansi, uji coba, retur) -> batas waktu atau kuota yang NYATA -> satu ajakan bertindak. Beri 3 paket (hemat, utama, premium) dengan paket utama ditandai.

**4. Funnel dan metrik**

| Tahap | Tujuan | Tindakan | Metrik sehat |
| --- | --- | --- | --- |
| Awareness | dikenal | konten, iklan, kolaborasi | jangkauan, CTR 1-3% |
| Minat | meninggalkan kontak | lead magnet, katalog, demo | biaya per lead |
| Pertimbangan | yakin | bukti, perbandingan, tanya jawab | balasan chat, permintaan penawaran |
| Closing | bayar | penawaran, pengingat, kemudahan bayar | konversi |
| Repeat | beli lagi dan rekomendasi | follow-up, program loyal | repeat rate, referral |

**5. Skrip chat (WhatsApp/DM)**

Pembuka (jangan menjual): `Halo <nama>, saya <nama> dari <brand>. Saya lihat <konteks spesifik yang membuat menghubungi>. Boleh tanya, saat ini <masalah> lebih sering terjadi di <A> atau <B>?`
Kualifikasi (3 pertanyaan): kebutuhan utama, waktu butuh, kisaran anggaran.
Penawaran: rangkum ulang masalah mereka dengan kata mereka -> solusi -> harga -> `Mau saya buatkan pesanannya sekarang atau ada yang ingin ditanyakan dulu?`
Penutupan: konfirmasi pesanan, cara bayar, estimasi kirim, dan ucapan terima kasih.

**6. Follow-up (tiap pesan membawa nilai baru)**

| Waktu | Isi | Contoh |
| --- | --- | --- |
| H+1 | Ringkas dan ramah | "Kalau ada yang kurang jelas dari penawaran kemarin, saya siap bantu." |
| H+3 | Nilai tambah | tips, studi kasus, jawaban pertanyaan yang sering muncul |
| H+7 | Penawaran terakhir | alasan jujur (kuota, harga naik, periode berakhir) |
| H+30 | Reaktivasi | kabar baru atau penawaran berbeda |

Berhenti setelah 4 kali tanpa respons, atau langsung bila diminta.

**7. Menangani keberatan** (dengar -> akui -> gali -> jawab -> konfirmasi)

| Keberatan | Pertanyaan penggali | Arah jawaban |
| --- | --- | --- |
| "Mahal" | "Dibandingkan dengan apa?" | tunjukkan nilai per hari/pemakaian, paket lebih kecil, cicilan |
| "Nanti dulu" | "Apa yang membuat masih ragu?" | selesaikan keraguan nyata, atau jadwalkan kontak dengan tanggal |
| "Bandingkan dulu" | "Apa yang paling penting bagi Anda?" | tabel perbandingan jujur pada kriteria itu |
| "Tidak percaya" | "Apa yang akan membuat Anda yakin?" | bukti, garansi, uji coba kecil |
| "Tanya suami/istri/atasan" | "Apa yang akan mereka tanyakan?" | siapkan ringkasan untuk diteruskan |

**8. Pipeline (tabel kerja)**

`Nama | Sumber | Tahap (Baru, Dihubungi, Dikualifikasi, Penawaran, Negosiasi, Menang, Kalah) | Nilai | Tindakan berikutnya | Tanggal | Catatan`

Tinjau tiap hari: yang tanggalnya terlewat dikerjakan dulu. Catat alasan kalah, itu data terbaik untuk memperbaiki penawaran.

**9. Eksperimen** (satu variabel sekali): judul, harga, bonus, urutan pesan, jam kirim. Tulis hipotesis, ukuran sampel minimal (misalnya 30 per varian), metrik, dan kapan berhenti. Jangan menyimpulkan dari 3 percobaan.

**10. Format keluaran standar:** ringkasan strategi (5 baris), kalkulator target, ICP, penawaran, skrip siap kirim per kanal, jadwal follow-up, tabel pipeline kosong, dan 3 eksperimen pertama.

## Pitfalls

- Menjual di pesan pertama; pesan panjang tanpa satu ajakan jelas.
- Diskon sebagai alat utama: menurunkan nilai dan margin. Beri bonus atau paket, bukan potongan.
- Urgensi, stok, atau testimoni palsu. Ini merusak kepercayaan dan melanggar etika serta aturan platform.
- Follow-up yang hanya mengulang ("sudah baca belum?").
- Tidak mencatat alasan kalah.

## Verification

- Setiap pesan punya satu tujuan dan satu ajakan; tidak ada klaim yang tidak bisa dibuktikan.
- Kalkulator target memakai rumus tertulis dan asumsi yang ditandai.
- Ada jadwal follow-up bertanggal, tabel pipeline, dan metrik per tahap.
